# MERN-Fullstack-Food-Ordering-Platform

This is a food ordering platform built using the MERN stack.



Email: alexanderforprofession@gmail.com / alexanderforwork@outlook.com



I believe that in the AI era, a software engineer is like the conductor of a symphony orchestra. A software engineer does not need to manually write every line of code; instead, software engineer could direct agents to do the coding work. However, they must clearly understand various technical details—just as an orchestra conductor does not need to perform personally but must still understand how instruments are played. This project is a case of “the conductor practicing in person.” All the code in this project was handwritten by me rather than generated by AI. This is not because I don’t know how to use AI; on the contrary, I use AI every day and firmly believe that LLMs are a groundbreaking technology. It’s just that an orchestra conductor also needs to practice their own craft.
